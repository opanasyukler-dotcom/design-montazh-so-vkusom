2 сторис 1080×1920. Рядом с каждым `.mp4` лежит `.jpg` — его можно выложить как фото-сторис.
Рендер: `python3 tools/stories_lipo_or_implants.py <папка с drive/> stories_lipo_or_implants [номера]`.
