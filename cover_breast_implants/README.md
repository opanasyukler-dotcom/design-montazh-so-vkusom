# Обложка Reels: увеличение груди имплантами

`oblozhka.jpg` — 1080×1920, в стиле обложки «Комплексная операция»: чёрный фон, слева ДО, справа ПОСЛЕ,
сверху заголовок Bebas «УВЕЛИЧЕНИЕ ГРУДИ ИМПЛАНТАМИ» в одну строку.
Оба фото в одном масштабе, на одной линии плеч и обрезаны ровно: сверху по шее, снизу по кончикам пальцев.
Кожа на ДО подогнана по цвету под ПОСЛЕ. Татуировки убраны (предплечья и бок на ПОСЛЕ, точки на боку на ДО).
Всё важное — в центральной зоне 3:4, чтобы в сетке профиля ничего не обрезалось.

Рендер: `python3 tools/cover_breast_implants.py ДО.jpg ПОСЛЕ.jpg cover_breast_implants/oblozhka.jpg`
