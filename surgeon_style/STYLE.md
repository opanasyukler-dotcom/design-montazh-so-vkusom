# Стиль постов и сторис хирурга (по референсам)

Рендер: `python3 tools/surgeon_style.py ФОТО.jpg surgeon_style`

## Палитра бренда
| Токен | HEX | Где |
|---|---|---|
| NAVY | `#102E46` | основной фон, тонировка фото, текст на светлом |
| POWDER | `#E2D2D3` | акцентные заголовки, пузыри, кнопки, светлый фон коллажа |
| MAUVE | `#686068` | тонировка сторис, линии и точки на светлом фоне |
| DEEP | `#0A1622` | затемнение «кино»-кадров |

## Шрифты
- **Посты 4:5** — заголовки Bebas Neue (POWDER на тёмном, NAVY на светлом), текст Montserrat Light 300.
- **Сторис 9:16** — классический Montserrat: Bold 700 для акцента, Light 300 для остального. Bebas не используем.

## Приёмы из референсов
- Заголовок «лесенкой»: тонкая строка + маленькая подпись справа + огромное жирное слово (сторис 1).
- Пунктирные дуги через кадр, точка-стрелка как связка между строками.
- Фразы пациенток в пузырях-сообщениях + белая карточка со скрепкой для главной мысли.
- Одно большое слово и три «петлевые» стрелки к подписям.
- Иконки в тонком круге (лупа, «?», график, галочка, сообщение) для списков.
- Светлый коллаж: арки и круги с фото, пунктирная тропинка, короткие линейки между пунктами.
- Светящаяся линия-таймлайн с годами.
- Логотип ANNA TVAURI сверху по центру; в сторис текст держим в зоне 250–1670 px.
