# Сторис: коррекция груди без имплантов — только собственный жир

6 сторис 1080×1920 (видео со звуком). Рендер: `python3 tools/stories_breast_fat_only.py <папка с drive/ и asr/> stories_breast_fat_only [номера]`.
Монтаж речи: `tools/clean_speech.py` — убраны все паузы, «а/э», протяжные «ааа/эээ/мыыы» (`--drawn`, детектор в
`tools/voice_tools.py`), «ага», «ммм» и оговорка «как его пере…» (`--cut`); на стыках мягкие 12-мс переходы, громкость выровнена.
Голос пациентки изменён мягко (тембр выше на 16 %, высота на 11 %, без низкого «жуткого» звучания) везде, где она говорит, включая короткие ответы «да», «тут», «галифе»;
голос хирурга естественный. Проверено повторным распознаванием речи: слова целы, «ааа» не слышно.

```
clean_speech.py v2.mp4 asr/v2.mp4.json d1.mp4 4.2-32.0 --drawn --cut 11.08-11.56,14.68-15.0,31.95-33 --disguise 4.2-14.75,18.4-23.5,29.15-33.0
clean_speech.py v1.mp4 asr/v1.mp4.json d2.mp4 20.45-27.4 --drawn --cut 22.36-22.84 --disguise 8.9-27.6
clean_speech.py v1.mp4 asr/v1.mp4.json d3.mp4 37.5-44.8,47.4-49.8,52.3-61.9,94.6-97.2,100.6-102.0 --drawn --cut 61.30-61.95 --disguise 41.55-41.95,48.25-49.8,52.7-54.6,96.85-97.3,100.6-102.0
clean_speech.py v3.mp4 asr/v3.mp4.json d4.mp4 0-27.3 --drawn --cut 0-1.80,8.62-9.15,9.86-10.44,10.12-10.62,22.42-23.16
clean_speech.py v4.mp4 asr/v4.mp4.json d5.mp4 0-31.4 --drawn --cut 0-1.77,26.08-26.95
```
